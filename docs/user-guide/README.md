# EGYXplore User Guide

EGYXplore helps travelers discover Egyptian destinations, build trips, complete photo missions, earn points, redeem rewards, and ask the travel assistant questions.

## Main Tabs

- **Explore:** Browse the map, search destinations and branches, view place information, and request a route.
- **Sanctuaries:** Browse destination cards, add places to an itinerary, create saved trips, view saved trips, and open the AI assistant.
- **Missions:** View available photo missions and review completed missions.
- **Rewards:** Check your points, redeem available rewards, and view voucher history.
- **Account:** View profile information and journey statistics, edit supported details, open Help, and adjust settings.
