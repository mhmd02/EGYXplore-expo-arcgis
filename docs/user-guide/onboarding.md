# Onboarding

After registration, EGYXplore offers two optional steps. You can skip them and continue to Explore.

## Step 1: Appearance and Interests

1. Choose **Light** or **Dark** appearance.
2. Select any interests shown on the screen.
3. Tap **Next**.

The selected interests are sent to your profile when the save request succeeds. If saving fails, an error appears and you can retry. The selected theme changes the current app appearance, but this build does not persist the theme in the profile or device storage.

To bypass onboarding, tap **Skip All**. This goes directly to Explore without saving the current Step 1 selections.

## Step 2: Profile Picture

1. Tap the profile-picture circle.
2. Choose the camera or gallery option.
3. Select or take a picture if you want one.
4. Tap **Finish**.

The profile picture is optional. You can press **Finish** without selecting one. **Back** returns to Step 1.

## After Onboarding

You can edit interests later from **Account** → **Personal Information**. Appearance can be changed from **Account** → **Settings**, but current settings are in-session controls and are not reliably persisted after a restart.

## If Something Goes Wrong

- If interest saving fails, retry while connected to the internet or use **Skip All**.
- If camera or gallery access is denied, enable the required permission in device settings.
- If choosing a picture is cancelled, continue by pressing **Finish** without a picture.
